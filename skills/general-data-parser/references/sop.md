# 解析 SOP

## 1. 固定任务与 profile

确定用户需要全文提取、结构化字段、检索文档还是指定 schema。确定对象边界：文件、工作表、记录集合、组件或媒体片段。多文件工程的入口与依赖属于同一快照。

识别实际内容、容器签名、编码和格式版本，后缀只作线索。混合目录逐类分流。URL 保存取得时间、最终 URL、实际响应字节与内容类型；动态 DOM 与原始响应分别记录。数据库优先用提供的导出；实时读取须固定查询及一致性快照。

在 profile 记录格式、对象规则、解析工具/版本/实际参数、依赖策略、必要字段、单位/坐标/时区、观察策略、摘要归属、文件映射、模板、检查与交付范围。普通解析选 summary_owner=none；用户要求独立摘要时选 local；OV 入库选 backend 并注明 backend=openviking。凭据不进入产物。常规选择直接记录；仅对影响交付且无法推定的信息询问用户。

能力分为 available（发现工具）、sample_verified（样本验证）和 unsupported。发现一个库不代表验证了全部格式版本。

## 2. 快照实际输入

在独立临时目录保存源字节和实际用到的依赖，计算逐文件哈希。解析与预览读取同一快照，不能用同名库文件替换用户字节。外部源库要记录实际版本与内容。

按任务范围展开容器和依赖。拒绝路径跳转和越界链接，为递归、大文件与解压设置合理资源限制。截断、抽样和未读部分进入覆盖报告。对象 ID 规范化后重名必须解决；保留原名映射。

## 3. 提取可定位的事实

优先用匹配格式的可靠库/API。每条事实记录 kind、status、value、单位与 basis：

- source_declared：文件明确声明的内容，只证明源有该声明。
- extracted：解析、OCR、转录或模型提取结果，记录方法和误差。
- computed：基于源数据的计算，保留公式、输入与回执。

定位使用页/区域、工作表/单元格、记录键/JSON Pointer、行/字节段、媒体时间段、CAD 实体/实例。页码注明起算值，时间注明单位/时基，偏移注明编码与规范化方法。

关键数值、否定词和结构关系回查源证据。OCR/转录置信分数只是工具信号。保留原值与规范化值；不能猜测单位、坐标或类别后写成源声明。未知数量不用 0 代替，未解析列表不等于已证明为空。

## 4. 按需生成并读取观察证据

profile 指定 required / optional / not_applicable。版式、图表或外形影响任务时真实渲染；音视频读取实际片段，明确抽帧与转录范围；纯结构化数据可直接核对记录。

回执记录输入、实际工具/模型、参数、执行结果、输出哈希和范围。图像需可解码且对象可辨认；透明背景与显示合成颜色分别判断。生成式图片不能替代输入的视觉证据。

实际读取后才写 reviewed、观察者、时间和定位。reviewed 表示动作发生，不专指人工，也不证明内容全对；模型来源始终保留。未读取为 not_run，失败为 failed。

用途、意图、隐藏结构放入 hypotheses；没有合理推断时保留 unknown。对可检验的观察核对对象数量、文字、空间关系、数值与时间对应。矛盾无法修正时，必需检查失败。

## 5. 生成文档

按 [文件契约](output-contract.md) 生成 facts、observations、asset。仅 local 摘要模式增加 L0/L1，并核对未知、单位、否定、覆盖范围与推断边界。OV/backend 模式在本地交付时不要求这两个文件；等待后端生成后再核验。

正文可按 profile 限长，但说明展示量/总量并链接完整事实。表格、章节、关系和多模态定位不能只剩无法回读的摘要。先生成 manifest，再写验收报告的 manifest 哈希，避免自引用。

## 6. 验收与交付

先检查完整性，再检查格式内容和语义一致性。本地必要项实际通过才交付 local_ready；未执行的 publication_checks 不阻塞这个状态。published 必须另有发布和后端摘要的真实回读结果。可选缺口须披露并用 local_ready_with_limitations；不能把失败的必需项改成可选以通过。

先用小样本覆盖正常与主要失败类型，再批量处理。逐对象保存结果，部分失败不能报告整批通过。用户要求发布时执行 [发布流程](publication.md)，分别报告本地和远端状态。

## 重跑与缓存

复用时校验源闭包、工具/配置、profile/模板、模型/提示词和输出哈希；多用户缓存按调用方隔离。成功渲染可以在模型失败后复用，失败观察不能作为完成结果。

源、图像、配置或正文变化时，使相关检查失效。用有来源绑定的检查点续跑，保留真实回执；不能仅凭旧 running 字段判断进程存活。
