# 工程数据统一验收标准

General Engineering Parsing Acceptance 1.0。统一的是以下门槛、状态和证据要求；数据结构与专项算法由格式适配器决定。格式支持不能只靠名称或可导入的库声明。

## 所有格式共同遵守

| ID | 标准 | 通过条件 |
|---|---|---|
| E01 来源与版本 | 实际输入可追溯 | 原字节及用到的依赖保留；源、配置、代码版本与产物哈希绑定同一对象 |
| E02 能力与结构 | 解析范围真实 | 格式与子集已确认；必需结构和引用有效；不支持内容失败或按预先约定范围披露 |
| E03 数据保真 | 值、类型、精度不被默改 | 数字与字符串、null 与 0、缺失与空集合分开；转换满足声明精度/容差；NaN/Infinity 不能伪装成有效数据 |
| E04 工程语义 | 单位/坐标/时间有依据 | 保留源声明和调用方假设；未知明确记录；必需单位、时区或坐标不能靠猜测通过 |
| E05 覆盖 | 处理量可说明 | 报告总量/处理量和适配范围；不因坏行、资源上限或未知实体静默截断 |
| E06 定位与方法 | 结果可回到证据 | 行/列、Pointer、节点路径、字节偏移或实体引用可重放；计算关联算法和输入 |
| E07 一致性 | 派生结果可核对 | 检查计数、引用、数值关系、正文和实际数据；按格式执行专项不变量 |
| E08 可重复验证 | 真正执行检查 | 重读源文件，比较完整表示、事实与文档；以独立已知答案和反例验证适配器 |
| E09 完成判定 | 状态符合证据 | 必需项 fail/unknown/unsupported 不得就绪；可选限制披露；未观察不能填 reviewed |

哈希一致证明字节和版本绑定。重放一致证明当前代码对源和产物的解释一致，不能单独证明算法没有系统性错误。新适配器必须有独立预期结果、反例和适用边界。

## 首批代码实现及专项门槛

| 格式 | 代码检查 | 边界 |
|---|---|---|
| CSV / TSV | 矩形行列、唯一表头、字符串单元格往返、物理行定位 | 默认首条记录为表头，--no-header 可关闭；不猜数值类型或物理单位 |
| 时序表 | 显式时间列、严格递增/非递减、精确数字时间单位换算、ISO 时区 | 数字单位 s/ms/us/ns，起点不猜为 Unix epoch；ISO 须含秒和时区，最多六位小数；更高精度用数字轴 |
| JSON / JSONL | 拒绝重复键和非法常量，保留层级、顺序、Pointer/行定位、数字词法 | 数字以字符串加 numeric_tokens 类型映射表示，不能按普通字符串解释；JSONL 空流可证明为零记录 |
| XML | 根元素树、命名空间、属性、text/tail、子节点顺序及往返 | DTD/实体不支持；声明和根外节点留在原件；不执行 XSD/工程域语义推断 |
| STL | 二进制长度/面数或 ASCII facet 语法、有限坐标、包络、退化面 | binary header 以 solid 开头仍按真实长度识别；不推断颜色、单位和制造可用性 |
| OBJ | 顶点、UV、法向声明、正负索引、面引用、包络与退化面 | 网格子集；未知几何指令失败；材质指令保留但不加载材质/纹理；不声称多边形已有可靠三角剖分 |

网格计算使用 binary64。默认坐标转换容差为绝对 1e-9、相对 1e-12，按原始坐标单位计算并写入 profile，可显式调整。包络是已解析顶点极值，不证明曲面精确极值、封闭性、流形性、自交、面平面性、碰撞、公差或承载。

未知单位且允许原始坐标时为 local_ready_with_limitations；--require-unit 下未知单位必须失败。--require-observation 下，解析后保持 visual_review_required，等待真实审阅。

## 两层可执行验收

~~~bash
python3 scripts/verify_bundle.py /path/to/result --require-ready
python3 scripts/verify_engineering.py /path/to/result --require-ready
~~~

第一条检查契约、哈希和记录的门槛。第二条对内置适配器产物实际重读源、运行解析和专项检查、比较 data/parsed.json、facts 和 asset；即使错误数据的哈希被重算，也会检测与源解释不一致。

核对用户要求是否超出适配范围。代码通过不能把必需材质、单位或性能降级成可选。OV 已提供所需工程结果时复用其输出，按同一 E01–E09 核对；没有专用重放器时记录真实使用的核验方法。

## 新格式准入

遵循 [开发接口](adapter-development.md)：可执行解析、范围声明、定位、专项检查、独立正例和失败样本。STEP/IGES/DXF/IFC、HDF5/NetCDF/VTK 当前没有内置实现；实际实现及样本验收通过后才加入 --list-formats。
