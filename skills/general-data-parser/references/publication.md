# 可选发布与恢复

本地交付完成本地门槛即可。用户要求且已授权入库时继续，不重复询问同一授权。profile 记录后端、namespace、URI 映射、摘要所有权与公开接口。

1. 本地验收完成，列出精确 URI、版本与预期哈希。
2. 目标不存在则创建，相同字节则复用，同身份同版本不同字节则 conflict。版本覆盖源、配置、观察和规定正文。
3. 使用条件写入、幂等键或单写入者，记录并发边界。网络结果不明时保留 remote_unknown，先回读实际副作用，再恢复缺失部分。
4. 回读全部必需文件；服务包装过的正文按 profile 明确提取规则后比较。
5. 检查索引/同步，执行目标限定的真实查询，再回读命中的来源。通过本次全部门槛才 published。

报告记录 remote.bytes、remote.index、remote.query、目标 URI、方法和回执。必要接口不支持时记录 unsupported，不能假填 pass。

## 摘要、隐藏来源与锁

后端自动生成摘要时，保留原生结果和回执。通过受支持接口映射规定正文，或采用用户允许的 custom 关系并验收；不覆写受保护元数据。

同步前检查是否携带隐藏源目录、清单和证据。先验证目标身份，再同步正文与来源。恢复检查点绑定输入、目标和预期哈希，不能因临时源已移动就清空目标。

锁/租约覆盖实际写入和移动路径：临时源、目标和父导航分别确认。释放派生锁时保留调用方锁；成功的一次写入不等于整个流程完成。

## 缓存与失效

缓存键包含实际源闭包、工具/配置、profile/模板、模型/提示词、语言及调用方隔离范围。命中后核验输出哈希；失败结果不是完成缓存。

verify 只检查。远端漂移时标 invalidated，修复作为新的已授权发布执行。历史 pass 不能自动沿用为当前版本证据。
