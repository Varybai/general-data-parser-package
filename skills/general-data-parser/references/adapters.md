# 格式适配与专项检查

目标后端已有可用解析路由时，优先直接复用。下表用于核查后端产物，或在独立解析/已确认的缺口范围内选择工具。它不是要求每类输入都在 Agent 端重新解析，也不是已实现支持清单。适配器可以组合 CLI、解析库、软件 API 和模型。新增格式先验证代表性输入，再记录支持范围。

| 输入族 | 保留结构与定位 | 格式专项核查 |
|---|---|---|
| TXT / Markdown / HTML | 编码、标题、链接、代码块、表格；行/字节段、DOM 元素 | 编码损失、阅读顺序、表格结构、链接；原始 DOM 与动态内容分开 |
| PDF / DOCX / PPTX | 页/节/幻灯片、阅读顺序、表格、脚注、图片；页/区域/元素 ID | 总页数、漏页、合并单元格、关键字段；扫描页 OCR 回查，图表实际看图 |
| CSV / XLSX | 原始值、类型、空值、表、公式与显示值；主键/单元格 | 分隔符、行列数、重复表头、精度、空值与 0、隐藏行列；缓存值不等于重算 |
| JSON / JSONL / XML / YAML | 层级、类型、数组顺序、命名空间；Pointer/记录 ID/XPath | 无效行、重复键、截断、null/缺失、精度；XML 不隐式加载外部实体 |
| 日志 / 代码 / 数据库导出 | 时间戳、事件、符号/AST、表关系；行段/符号/主键 | 时区、跨行事件、记录覆盖、采样；静态解析不证明动态行为 |
| 图像 / 扫描件 | 原像素、朝向、OCR 区域、观察；图像哈希+区域 | 解码、裁剪旋转、透明度、关键文字；无标定不推物理尺寸 |
| 音频 / 视频 | 音轨、帧时基、转录、时间段；轨道+秒/帧时间 | 时长、漏段、重叠语音、关键字、音画对应、抽帧覆盖 |
| CAD / BIM / 网格 | 入口/依赖、单位、坐标、几何、实例、声明接口；对象/源行/坐标 | 缺依赖、未知单位、变换、包络算法误差、对象数；外形不证明装配/载荷 |
| 压缩包 / 多文件工程 | 成员、入口、相对引用；容器+成员路径/哈希 | 越界、重名、循环引用、资源上限、遗漏；成员与整包状态分开 |

## 本地适配器最小结果

1. 实际源快照与依赖清单。
2. 格式、工具/版本、配置、支持范围和损失。
3. 结构化事实、来源定位与可重算方法。
4. 按 profile 要求的观察证据与执行回执。
5. 处理覆盖量及内容验证方法。

缺能力时返回状态和原因。替换后缀、工具名字或调用通用模型，不构成新格式支持证明。

## 覆盖与新适配器验收

先清点对象/页/行/记录/时长，再报告实际处理量。大输入可按任务分层抽样，保留分母、采样方法与遗漏风险；用户要求的全量关键字段不能用抽样替代。

至少验证正常样本、必要信息缺失、部分支持/截断、源或配置改变后的旧证据失效。需要观察时增加“观察与可计算事实矛盾”。专项检查 ID 加入 profile.required_checks。
